# Spectra bench reports

Local scratch output from `spectra-bench` runs. Everything here except this README is gitignored.

Decision-grade JSON from AWS campaigns (`SPECTRA_BENCH_HARDWARE=aws-*`) isn't committed to this repo.

Naming: `{experiment}-{storage}-{topology}-{hardware}.json` (or `multidw-*` for multi-DW / BM-SW7 / BM-SW8).

Non-AWS / local / WSL smoke JSON stays here and is never kept. Pull decision-grade JSON from the AWS campaign hosts after a run.

Scoreboards: [`docs/bench/PERFORMANCE.md`](../../../docs/bench/PERFORMANCE.md).
